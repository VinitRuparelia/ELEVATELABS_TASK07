# ELEVATELABS_TASK07 : Basic Sales Summary from SQLite Database using Python
Sales data analysis using SQLite, SQL, and Python to generate revenue trends and insights with visualizations.

📊 **Objective**  
Use SQL inside Python to pull simple sales information (like total quantity sold and total revenue) and display it using basic print statements and a simple bar chart.

🧰 **Tools Used**  
- **Python** (with `sqlite3`, `pandas`, `matplotlib`)
- **SQLite** (built into Python — no setup!)
- **Jupyter Notebook** or a `.py` file

📂 **Dataset**  
Create a small SQLite database file (`sales_data.db`) with just one sales table.

📈 **Deliverables**  
- **Python script** (or notebook) that:
  - Connects to `sales_data.db`
  - Runs 1–2 SQL queries
  - Displays output using print and basic matplotlib bar chart

🔧 **Steps Involved**  
- **Database Connection**: Connect to the SQLite database.
- **SQL Queries**: Extract relevant sales data using SQL.
- **Data Loading**: Load the query result into a pandas DataFrame.
- **Data Visualization**: Display results with a simple bar chart.
- **Save Output**: Optionally save the generated chart to a file.

💡 **Outcome of Task**  
- Learn how to write basic SQL queries.
- Practice importing SQL data into Python.
- Perform simple data summaries.
- Create your first sales chart.
